# Safety

Read-only inspection is the default. Obtain explicit user authorization immediately before halting, resuming, stepping, inserting/removing breakpoints, flashing/erasing, reset, memory/register writes, starting potentially actuator-controlling firmware, or bulk hardware tests. Run control uses `--authorize-run`; reset, flash, memory writes, and breakpoint changes use `--authorize`. These flags are explicit CLI confirmation, not a substitute for informed user authorization. Record target-affecting actions. Never disable interlocks, emergency stops, or protection logic. Do not expose OpenOCD on a network interface unless the user specifically requests and understands it.
