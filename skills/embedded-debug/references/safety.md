# Safety

Read-only inspection is the default. Ordinary variable reads accept simple identifier/member paths such as `motor_speed` or `controller.pid.kp`. GDB expressions can execute functions or assign values, so any expression outside that restricted grammar requires explicit user authorization and `--authorize-expression`; do not use arbitrary expressions on physical hardware unless the user approves the exact expression and its possible effects. Obtain explicit user authorization immediately before halting, resuming, stepping, inserting/removing breakpoints, flashing/erasing, reset, memory/register writes, starting potentially actuator-controlling firmware, or bulk hardware tests. Run control uses `--authorize-run`; reset, flash, memory writes, and breakpoint changes use `--authorize`. These flags are explicit CLI confirmation, not a substitute for informed user authorization. Record target-affecting actions. Never disable interlocks, emergency stops, or protection logic. Do not expose OpenOCD on a network interface unless the user specifically requests and understands it.
