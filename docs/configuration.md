# Configuration

No project config file is required. `edbg discover --json` reads VS Code launch/tasks, literal OpenOCD invocations in CMake/Make/shell scripts, existing Make/CMake/PlatformIO build and flash targets, ELF outputs, and loopback listeners owned by OpenOCD. A candidate service is not trusted until GDB connects and reports target state. Existing project settings are preferred; `edbg.toml` or `.edbg.toml` is an optional strict override. Unknown TOML keys are rejected. Tool path precedence is CLI override, explicit project TOML value, then PATH. OpenOCD host must be loopback. Complete configs can be passed with `--openocd-config`; otherwise the discovered IDE/build command or user-provided interface/target/board settings are used. An OpenOCD board script or complete config is valid without separate interface and target files. Additional OpenOCD commands can be repeated CLI arguments or TOML strings.

Discovery is deliberately conservative: it does not execute build, flash, or shell scripts to learn their effects. It reuses literal argument vectors and known build-system targets. If a command is generated dynamically, has unresolved variables, or multiple candidates remain, review it and pass only the missing settings explicitly. Flash and other target-changing operations still require explicit authorization.

Build commands are arrays such as `command = ["cmake", "--build", "build"]` to avoid implicit shell execution. GDB can differ per target with `--gdb` or `[tools].gdb`.
